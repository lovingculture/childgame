# 우리는 구조대 (childgame)

한글, 수학, 과학을 게임으로 구조하며 배우는 Next.js 웹앱입니다. 받침구조대·숫자구조대·생명구조대에서 기본·도전·최고 수준을 선택할 수 있습니다.

## 실행

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 열 수 있습니다.

```bash
npm test
npm run typecheck
npm run build
npm start
```

이 작업 환경은 기본 npm 실행 파일이 없어 프로젝트의 `.tools/package/bin/npm-cli.js`를 사용했습니다. 해당 환경에서는 `node .tools/package/bin/npm-cli.js run dev`로 실행할 수 있습니다. 일반 Node.js 설치 환경에서는 위의 npm 명령을 사용하세요.

## 학습과 보상

- 기본: 7개 월드, 35개 스테이지, 316문제. 기존 마을은 일반 10문제와 보스 12~15문제이며 어휘·한자 마을은 단계마다 5문제입니다. 반복 문항을 줄이고 보스의 문맥·활용형 판단을 강화했습니다.
- 도전: 초등 6학년 수준을 목표로 한 복합 빈칸·문장 교정 175문제(35단계 × 5문제). 문맥·표준어·활용형·띄어쓰기를 함께 판단합니다. 난이도 선택은 작전 지도와 월드 화면에 있습니다. 새 녹음은 필요하지 않습니다.
- 받침·단어·문장·그림·맞춤법·파일 음성 문제를 제공합니다.
- 기본 문제에서 틀린 문제만 최대 두 차례 복습합니다. 마지막 오답은 결과에 표시합니다.
- 기회 3개를 모두 사용해도 지원 모드에서 학습을 이어 갑니다.
- 점수·콤보·별·최초 클리어 조각·월드 배지·누적 별 보상을 제공합니다.
- 모든 월드와 단계를 자유롭게 선택할 수 있습니다. 완료 여부와 별은 최초 풀이의 정답률을 기준으로 기록합니다.
- 45별 보너스 연습은 별·조각을 추가 지급하지 않습니다.
- 최고 수준: 중학교 1학년 수준을 목표로 한 독해·문장 구조·어문 규칙 종합 175문제(35단계 × 5문제). 세 난이도에서 총 666문제를 제공합니다.
- 최고 기록과 소리 설정은 이 브라우저의 localStorage에 저장됩니다. 기본·도전·최고 수준 기록은 각각 별도 키에 저장합니다. 브라우저나 기기를 바꾸면 기록은 공유되지 않습니다.

## 문제 수정

현재 기본 문제 편집본은 `data/basic-questions-266.csv`, 도전 문제는 `data/challenge.ts`, 최고 수준 문제는 `data/expert.ts`입니다. 처음 제공된 `batchim_questions_266.csv`는 참고용으로 보존했습니다. [data/QUESTIONS.md](data/QUESTIONS.md)에 반영 방법을 정리했습니다.

```powershell
pwsh -File scripts/import-questions.ps1
```

문제 ID와 스테이지별 수, 보기와 정답을 테스트로 검사합니다. 사용자 CSV의 최종 스테이지 구성은 그림 2·문장 4·음성 4·맞춤법 3·단어 선택 2문제입니다.

## 녹음 파일

합성 음성은 생성하지 않습니다. [public/audio/녹음대본.md](public/audio/녹음대본.md)의 문장을 읽고 `public/audio/`에 문제 ID를 파일 이름으로 저장하세요.

```text
public/audio/5-3-01.m4a
public/audio/5-3-02.mp3
public/audio/5-5-03.wav
```

mp3, m4a, wav를 지원합니다. 같은 문제에 여러 형식이 있으면 mp3 → m4a → wav 순서로 선택합니다. 파일을 추가한 뒤 페이지를 새로고침하면 연결됩니다. 해당 스테이지의 필수 음성이 누락되면 녹음 준비 중으로 표시합니다. 녹음 파일은 정답 대본과 같은 순서로 읽어 주세요.

```bash
npm run audio:check
```

미등록 파일이 있으면 목록과 종료 코드 1을 표시합니다. 파일 존재 검사는 녹음 내용이 대본과 일치하는지까지 판정하지 않습니다.

프로젝트를 Git 저장소에 올리고 Vercel에서 Next.js 프로젝트로 가져옵니다. 빌드 명령은 `npm run build`이며 별도 환경 변수나 데이터베이스가 필요하지 않습니다. `public/audio` 파일도 함께 올려야 합니다. 배포 후 녹음이나 CSV를 수정할 때에는 다시 배포합니다. 현재 작업에서는 외부 배포를 수행하지 않았습니다.

## 숫자구조대

홈에서 받침구조대와 숫자구조대를 선택하고, /numbers에서 기본·도전(초3~4)·최고 수준(초5~6)을 고릅니다. 기본은 기존 9개 영역·45단계를 유지합니다. 도전은 덧셈·뺄셈·곱셈·나눗셈의 20단계, 최고 수준은 네 연산과 혼합 계산의 25단계로 총 90단계입니다. 분수·대분수·소수까지 확장하고 모든 단계에서 매번 새로운 10문제를 만듭니다. 나머지 있는 나눗셈도 포함됩니다.

기본 숫자 기록은 number-rescue-progress-v1에 유지하며, 도전과 최고 수준은 별도 저장 키를 사용합니다. 받침구조대 기록과도 분리됩니다. 문제 생성은 lib/number-questions.ts와 lib/number-grade-questions.ts, 학년별 영역과 단계는 data/numbers.ts에서 관리합니다. [학년별 구성과 검증 기록](docs/number-levels-verification.md)을 참고하세요.

## 생명구조대

개발 중인 과학·생명 학습 게임의 화면 표시명은 **생명구조대**입니다. 메뉴, 홈 카드, 페이지 제목과 안내 문구에는 이 이름을 사용합니다.


## 숫자 구조와 생명 구조

- 숫자 구조: 기본 45단계, 도전 20단계, 최고 수준 25단계. 매번 새로운 계산 문제를 생성합니다.
- 생명 구조: 6개 테마, 난이도마다 30단계. 관찰·개념·자료 해석 문제를 제공합니다.
- 게임과 난이도마다 별과 완료 기록을 따로 저장하고, 누적 별에 따라 모자·배지·황금 헬멧·트로피 보상을 지급합니다.
- 학습 기록은 현재 기기와 브라우저의 localStorage에 저장됩니다.
