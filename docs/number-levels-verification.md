# 숫자구조대 학년별 연산 확장

2026-10-05. 기존 기본 45단계를 유지하고 도전(초3~4) 20단계, 최고 수준(초5~6) 25단계를 추가했다. 단계마다 새 문제 10개를 생성하고 자유롭게 선택한다.

| 난이도 | 덧셈·뺄셈 | 곱셈 | 나눗셈 | 혼합 계산 |
| --- | --- | --- | --- | --- |
| 도전 | 세·네 자리 수, 같은 분모의 분수, 소수 한·두 자리 | 두 자리×두 자리, 세 자리×한·두 자리, 빈칸, 문장제 | 한·두 자리로 나누기, 세 자리 피제수, 몫·나머지, 문장제 | 없음 |
| 최고 수준 | 다른 분모의 분수, 대분수, 소수 두·세 자리, 문장제 | 분수×자연수, 분수×분수, 대분수×분수, 소수×자연수·소수 | 분수÷자연수, 자연수÷분수, 분수·대분수÷분수, 소수÷자연수·소수 | 자연수의 계산 순서·괄호, 소수의 괄호 계산, 분수 혼합 계산 |

학년군별 수와 연산 범위를 참고한 구성이다. 학교별 교과서 전체 문항이나 다른 수학 영역을 옮긴 자료가 아니다. 도전의 같은 분모 분수 답은 원래 분모를 유지하며 정수인 결과는 정수로 표시한다. 최고 수준의 분수 답은 기약분수로 표시한다. 분수·소수 계산은 정수 분자·분모로 계산해 부동소수점으로 정답을 판정하지 않는다.

범위 참고: [교육부 2022 개정 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=), [한국과학창의재단 수학과 교육과정 시안 최종안 개발 연구](https://cdn.kosac.re.kr/files/legacy_data/jnrepo/upload/jnBrdBoard/202308/b800e7adf20d4ac2bf4892dddfb0fbcf_1692756609038.pdf).

## 기록

기본의 `number-rescue-progress-v1` 키를 유지한다. 도전은 `number-rescue-challenge-progress-v1`, 최고 수준은 `number-rescue-expert-progress-v1`로 점수·별·완료 기록을 분리한다. 선택한 난이도는 `number-rescue-level-v1`에 저장한다. 받침구조대의 난이도 선택과 기록에는 영향을 주지 않는다.

## 검증

- 학년별 45단계 × 세 seed × 10문항의 연산 값, 중복, 네 개 보기, 정답 포함, 정답 위치를 검사했다.
- 숫자구조대의 기존·추가 테스트 7개 통과, 실패 0개. 최종 소스를 복사한 별도 미리보기에서 TypeScript 검사와 프로덕션 빌드가 통과했다.
- 통분·약분, 같은 분모 유지, 소수의 정확한 결과, 괄호, 몫과 나머지, 기존 기록 보존과 세 난이도 저장 분리를 검사했다.
- 실제 브라우저에서 최고 수준의 소수 나눗셈 10문제를 모두 맞혀 1,550점·정답률 100%·별 3개·조각 1개를 확인했다. 지도 새로고침 후 별과 조각이 유지되고 도전으로 바꾸면 독립된 0개 기록이 표시되는 것을 확인했다.
- 도전 분수 문제의 보기와 정답 판정을 확인했다.
- 최고 수준의 `3/8 + 1/10 = 19/40` 정답 판정, 360px 모바일 화면의 난이도 선택과 소수 혼합 계산을 확인했다. 소수 보기는 한 줄로 표시되고 화면 가로 넘침은 없었다.
- 현재 서버의 빌드 폴더와 충돌하지 않도록 `.tools/number-level-preview` 사본에서 프로덕션 빌드와 최신 화면 확인을 진행했다. 미리보기 주소는 `http://localhost:3003/numbers`다. 주소가 달라 이전 미리보기의 브라우저 기록과 별도로 저장된다.
