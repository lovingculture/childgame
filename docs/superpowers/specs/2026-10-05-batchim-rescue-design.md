# 받침구조대 MVP 구현 설계

기준 문서: 사용자가 제공한 「받침구조대 통합 웹앱 설계서 v3」.

## 목적과 범위
초등학생이 받침을 선택하며 단어를 구조하는 학습 게임을 만든다. 랜딩, 월드 선택, 스테이지 선택, 플레이, 결과까지 완성한다. 로그인과 서버 저장, AI 추천은 이번 범위에 포함하지 않는다.

기존 폴더의 hwpx와 zip은 보존한다. zip에는 단일 HTML 시제품이 있으며 신규 Next.js 앱의 참고 자료로만 활용한다. 프로젝트는 현재 폴더에 생성한다.

## 구성
Next.js 최신 안정 버전, App Router, TypeScript, Tailwind CSS를 사용한다. 버전은 설치 시 공식 배포 정보를 확인하고 lockfile에 고정한다. 서버 컴포넌트는 공통 레이아웃과 경로 검증을 담당하고 게임과 저장 기능은 클라이언트 컴포넌트로 분리한다.

경로는 /, /game, /game/[world], /game/[world]/[stage]로 구성한다. 월드 경로는 설계서의 영문 slug, 스테이지 경로는 1~5 숫자를 사용한다. 잘못된 경로에는 404를 제공한다. 잠긴 경로에 직접 접근해도 플레이를 시작할 수 없다.

문제와 월드, 보상 데이터는 data/, 타입은 types/, 점수와 저장은 lib/, 게임 상태와 오디오는 hooks/에 둔다. 문제마다 고유 ID, 정답, 보기, 설명, 난이도를 제공한다.

## 학습 데이터
5개 월드에 각각 5개 스테이지를 둔다. 일반 스테이지는 10문제, 월드 1~3 보스는 12문제, 월드 4~5 보스는 15문제로 총 266문제를 제공한다. 문제가 같은 단어를 복습하더라도 질문과 문맥은 학습 목표에 맞게 구성한다. 보기에는 정답이 정확히 한 번 포함되고 중복 선택지가 없어야 한다.

월드별 학습 목표와 스테이지별 받침 범위는 v3를 따른다. 사용자가 제공한 batchim_questions_266.csv를 원본으로 사용한다. 최종 스테이지는 CSV 기준 그림 2, 문장 4, 음성 4, 맞춤법 3, 단어 선택 2문제로 구성한다. 전체 음성 문제는 14개다. 한글 음절의 받침 제거는 유니코드 음절 분해를 사용해 겹받침도 정확하게 표시한다.

## 게임 상태와 정답률
한 번 선택하면 정답 또는 오답 설명을 표시하고 다음 버튼으로 진행한다. 오답이면 복습 대기열에 추가한다. 기본 풀이 종료 뒤 틀린 문제만 최대 두 차례 재출제한다. 마지막에도 틀린 문제는 결과에 단어, 정답, 설명과 함께 표시한다.

별과 해금에 쓰는 정답률은 기본 문제의 최초 정답 수 / 기본 문제 수다. 복습 정답으로 정답률을 올리지 않는다. 처음부터 힌트를 써도 정답 여부는 유지하며 힌트 사용 횟수를 별도로 집계한다.

기회는 3회이며 오답마다 1회 감소한다. 0이 되면 지원 모드로 계속 진행한다. 지원 모드에서는 정답 기본 점수만 지급하고 힌트 감점은 적용한다. 오답 시 콤보는 0으로 돌아간다.

## 점수와 보상
정답 기본 100점, 최초 정답 20점, 10초 이내 정답 20점을 지급한다. 콤보 보너스는 중복 합산하지 않고 3~4콤보 10점, 5~9콤보 20점, 10콤보 이상 50점을 지급한다. 복습에서 해결한 문제는 기본 100점을 한 번만 지급한다. 이미 해결된 문제에는 추가 점수가 없다. 힌트는 문제당 한 번 사용 가능하며 20점 감점, 총점은 0 미만으로 내려가지 않는다.

정답률 70% 이상은 별 1개와 클리어, 80% 이상은 별 2개, 90% 이상이면서 힌트 2회 이하는 별 3개다. 별 3개 조건의 힌트를 초과하면 별 2개다. 각 스테이지 최초 클리어만 조각 1개를 지급한다. 재도전은 최고 점수·최고 별·최고 콤보를 갱신하며 기존 성취를 낮추지 않는다.

앞 스테이지를 클리어하면 다음 스테이지가 열린다. 월드 보스를 클리어하면 다음 월드가 열린다. 월드 전체 클리어로 해당 배지를 지급한다. 누적 별 보상은 v3 기준으로 표시한다. 45별 보너스 스테이지는 별도 연습 모드로 기존 문제를 복습하며 25개 정규 스테이지의 별과 조각을 추가로 지급하지 않는다.

## 음성
오디오 재생은 useAudio로 분리한다. 파일을 반복 재생할 수 있으며 문제 이동과 화면 이탈 시 재생을 중단한다. 재생 실패는 화면에 안내하고 다시 듣기를 제공한다.

사용자가 녹음 파일을 중간에 넣기로 했다. 합성 음성은 생성하지 않는다. public/audio에 문제 ID 이름의 mp3, m4a 또는 wav 파일을 넣으면 연결한다. 필수 파일이 없는 스테이지는 녹음 준비 중으로 표시한다. 이후 사용자가 제공한 m4a 14개를 등록했다. 녹음 내용과 대본의 일치 여부는 제작자가 최종 확인한다.

## 저장과 접근성
localStorage의 버전 있는 단일 키에 스테이지 기록과 설정을 저장한다. 저장 실패 시 이번 플레이를 유지하고 저장되지 않았다는 안내를 표시한다. 초기 렌더는 서버와 일치시키고 저장 로드 전 잠금 판정을 확정하지 않는다. 기록은 이 브라우저에만 유지된다.

화이트 배경과 파랑·보라 포인트, 넉넉한 여백, 20~28px 카드 모서리를 사용한다. 오리지널 구조대장과 받침 로봇은 SVG 또는 CSS로 제작한다. 버튼은 48px 이상, 키보드 포커스와 텍스트 상태 안내를 제공한다. 모바일 메뉴, 반응형 보기, 줄어든 동작 설정을 지원한다. 문의는 지정된 mailto 링크로 연결한다.

## 검증 기준
1. 25개 스테이지, 총 266문제, 스테이지별 개수, 고유 ID, 보기의 정답 포함 여부를 자동 검증한다.
2. 점수 경계, 지원 모드, 별 기준, 복습 최대 2회, 조각 중복 방지와 순차 해금을 테스트한다.
3. TypeScript 검사와 프로덕션 빌드가 통과한다.
4. 브라우저에서 랜딩부터 첫 스테이지 결과, 오답 복습, 새로고침 후 저장 복원까지 확인한다.
5. 모바일 화면에서 메뉴와 보기 터치 영역, 가로 넘침을 확인한다.
6. 모든 음성 파일이 존재하고 실제 오디오로 재생 가능한지 확인한다.

## 현재 환경 확인
Node.js v24.19.0은 사용 가능하다. npm 명령은 PATH에서 발견되지 않아 구현 시 번들 런타임 또는 npm 실행 경로를 확인해야 한다. 한국어 Microsoft Heami 음성이 설치되어 있다. 아직 앱 코드 생성, 의존성 설치, 빌드, 테스트는 수행하지 않았다.
